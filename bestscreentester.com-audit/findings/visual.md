# Visual / mobile audit - bestscreentester.com (2026-10-01)
Method: bundled capture_screenshot.py (desktop 1920x1080, mobile 375x812 @2x -> 750px wide PNGs, full-page for mobile) + source reading. Custom viewports (1440/390/360) and DOM measurement scripts are NOT possible with the plugin runner (bundled scripts only), so 360px overflow, computed tap sizes and CLS were not measured directly; tap sizes/contrast below are derived from Tailwind classes in source.
Screenshots: /Users/daniel/Codes/bestscreentester/bestscreentester.com-audit/screenshots/<page>/ (home, tools, dead-pixel-test, refresh-rate-test, fake-broken-screen, blog, guide); mobile-fold.png = first 812 CSS px.

## Findings
1. HIGH - Homepage showed Next's generic "This page couldn't load" error screen (white page, Reload/Back) on the first desktop and first mobile capture (both initial home captures; 8 later loads were fine). Transient, cause unverified (possibly a deploy/chunk mismatch window). No src/app/error.tsx or global-error.tsx exists, so users get an unbranded white screen. Evidence: first capture of home (overwritten by good retry; behaviour observed in-session). Fix: add src/app/error.tsx + global-error.tsx with dark-theme styling and reload; investigate the crash (check browser console on cold load).
2. MEDIUM - Refresh Rate launcher overlaps text on mobile: readout circles/"Measured from animation frames" (src/components/tools/RefreshRateTool.tsx:28) collide with the Start pill and "Tap for controls · Esc to exit" hint (src/components/tools/FullscreenStage.tsx:288) inside the aspect-video box (FullscreenStage.tsx:~246, ~192px tall at 375px). Evidence: refresh-rate-test/mobile-fold.png. Fix: when !active, render a compact/blank frame (renderFrame(index, active) already receives `active`) or hide the readout under the launcher.
3. MEDIUM - Accent text contrast: #d6336c on #0a0b0f = 4.26:1 (<4.5) for small eyebrow labels ("PANEL & BACKLIGHT", "MOTION & TIMING"); ToolCard "Open test ->" uses text-accent/70 (src/components/ToolCard.tsx:13), lower still (~3:1 est.). Fix: lighter accent for text (e.g. #ee5a8f) or drop /70.
4. LOW - Muted text text-foreground/50 (footer copyright, dates) = 4.6:1, borderline pass; text-foreground/60+ is fine (6.0+). Stage hint text-white/70 on grey preview of Fake Broken Screen ("Tap anywhere or press Esc to exit") is low contrast over the light cracked image (fake-broken-screen/mobile-fold.png); add a text shadow/pill background at FullscreenStage.tsx:288.
5. LOW - Tap targets under 44-48px: header nav links py-2 text-sm (~36px high, Header.tsx:19-27); frame-picker arrows px-3 py-1 text-sm (~28px high, FullscreenStage.tsx:~262,~275); footer links text-sm space-y-1 (~20px high, Footer.tsx:27-81). Fix: py-3/min-h-11, larger arrow buttons, space-y-2 + py-1 on links.
6. LOW - Brand wordmark truncates to "BestSc..." on 375px (Header.tsx:14 `truncate`) because nav takes the width. Evidence: every mobile-fold.png. Fix: hide wordmark text below ~sm (logo only) or shrink nav padding.
7. LOW - Guide article on mobile is a card inside page padding (p-6 inside px-4, blog/[slug]/page.tsx:80,113) so body text column is only ~285px wide; hero image text is tiny (guide/bestscreentester_com_mobile.png). Fix: p-4 / drop card chrome below sm.
